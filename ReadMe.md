Repositório dedicado aos meus estudos e à minha evolução na linguagem Java, reunindo exercícios, experimentos e projetos desenvolvidos durante meu aprendizado em programação.

Projetos:
- Arena - Sistema de combate PVE.
Projeto desenvolvido para estudar Programação Orientada a Objetos, distribuir responsabilidades e interações entre as classes.
- BancoDados - Sistema de gerenciamento de produtos.
Projeto desenvolvido para estudar a integração entre Java e bancos de dados relacionais.

Tecnologias: Java, Maven, JDBC e MySQL.
